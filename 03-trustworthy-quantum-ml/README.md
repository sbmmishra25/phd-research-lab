# 03 — Trustworthy Quantum ML

Research framework for robustness, uncertainty proxies and noise sensitivity in quantum/classical learning pipelines.

## Research Questions
- How stable are predictions under perturbations?
- How does finite-shot/noise variation affect confidence?
- Which explanations remain stable across seeds?

## Extensions
Add noisy QNNs, calibration curves, conformal prediction, counterfactual analysis and uncertainty intervals.
