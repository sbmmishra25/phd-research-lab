# 02 — Quantum Kernel Learning

Controlled comparison of classical kernel learning and quantum-kernel methods on low-dimensional nonlinear data.

## Hypothesis
Quantum feature maps may provide useful similarity representations for some problems, but evaluation must use matched splits and computational-cost reporting.

## Baseline
RBF SVM.

## Research Extensions
Fidelity quantum kernels, QSVC, kernel alignment, finite-shot studies, noise studies and multiple seeds.
