# 01 — Quantum-Enhanced Optimization

## Objective
Study QAOA for small combinatorial optimization problems with transparent classical references.

## Research Questions
- How does performance change with QAOA circuit depth?
- How sensitive are solutions to initialization and optimizer settings?
- How does the quantum formulation compare with exact enumeration on small instances?
- How does finite-shot sampling affect approximation quality?

## Method
The project now contains:
- `src/maxcut.py`: exact MaxCut enumeration used as the ground-truth reference for small graphs.
- `src/qaoa_maxcut.py`: executable QAOA MaxCut implementation using the current Qiskit Algorithms / Optimization stack.
- A matched comparison should report objective value, approximation ratio, runtime and resource measures.

## Metrics
Objective value, approximation ratio, runtime, circuit depth, number of qubits, optimization iterations and trainable parameters.

## Reproducibility
Use a fixed graph seed and QAOA seed for smoke tests. For research claims, repeat across graph families and multiple seeds.

## Extension
Add QAOA depth sweeps, finite-shot experiments, realistic noise models, warm starts, graph-size scaling and statistical confidence intervals.

> No quantum-advantage claim is made by this repository. Results must be generated by executing the experiments.
